What step 0 measured

1Update cadence ≈ 45 s

Per-vehicle ta advances on a firm ~45 s ceiling (median 44, p90 45, max 45) — not the 30 s DESIGN assumed. Drove the poll interval to 45 s and the freshness SLO to p99 < 120 s.

2Session ≥ 151 s

The apiCredentials cookie carried every call for the whole run with no re-auth. True ceiling unprobed — the ingester re-authenticates reactively on failure, not on a timer.

3No rate limiting seen

~1 request / 5 s for 150 s returned all 200s — no 429, no Retry-After. Undocumented ceiling, but far above our cadence.

4Docs lie about types

p arrives as a JSON string ("31971"), not the integer the docs claim — it broke the first decode. sv/is come back null. Structs are typed against the live payload.

5Empty line = 200 + []

An idle line — and even an unknown line code — returns HTTP 200 with vs:[], never a 404. Transport success ≠ semantic success: the exact case the future positions_ingested_total metric exists to catch.

6Midday volume

7,141 vehicles across 1,914 lines in service; busiest single line just 28. All of p,a,ta,py,px non-null across the whole sample.
